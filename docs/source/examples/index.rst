Habitat Guide
=============

One scientific task per page. Copy the Python, swap ``DATA`` /
``MODALITIES`` / ``ROI``. Figures on a page come from that page's
``plot_*`` call.

Imaging pages call :func:`~habit.datasets.fetch_demo` (downloads once).
In-memory pages use synthetic arrays.

Python first map: :doc:`../tutorial/quickstart_python`.
CLI / YAML: :doc:`../tutorial/quickstart` and :doc:`../configuration/index`.

CLI and YAML#

The habit command line and the YAML files are a shell over the Python API: every command runs the same analysis as the Python pages. YAML templates and habit commands live only in this section, not in the Habitat Guide.

Two subpages:

  • Command reference – every habit subcommand, what it does, and where its options are explained.

  • YAML configuration files – the YAML templates under config/ and the field reference for each workflow. Copy a file, edit the ★ fields (usually data and output paths), and run the matching command.

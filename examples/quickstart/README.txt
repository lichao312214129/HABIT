Get started
===========

**Background.** A habitat map splits a tumour into sub-regions whose voxels
behave alike across the input images.
**Purpose.** Build your first habitat map and feature table from the demo
pack, first in Python, then from a YAML file.

First habitat map from the official demo pack. Install HABIT first
(:doc:`/tutorial/installation`). The next page loads the same kind of
analysis from a v1 YAML document. CLI twin: :doc:`/tutorial/quickstart`.

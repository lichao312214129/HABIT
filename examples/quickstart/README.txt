Get started
===========

**Background.** A habitat map splits a tumour into sub-regions whose voxels
behave alike across the input images.
**Purpose.** Build your first habitat map and feature table from the demo
pack, first in Python, then from a YAML file.

First habitat map from the official demo pack. Install HABIT first
(:doc:`/tutorial/installation`). The next page runs the same analysis
from a v1 YAML document, and :doc:`/tutorial/quickstart` runs it from the
shell with ``config/habitat/config_habitat_quickstart_v1.yaml``. All three fit
the same four subjects with the same stages and seed, and give the same
habitat maps voxel by voxel.

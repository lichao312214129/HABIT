Get started
===========

**Background.** A habitat map splits a tumour into sub-regions whose voxels
behave alike across the input images.
**Purpose.** Build your first habitat map and feature table from the demo
pack, first in Python, then (briefly) from a YAML file and the ``habit``
command.

Install HABIT first (:doc:`/tutorial/installation`). The Python page is
the main walk-through; the YAML and CLI page runs the same analysis from a
v1 YAML document and from the shell with
``config/habitat/config_habitat_quickstart_v1.yaml``. All routes fit the
same four subjects with the same stages and seed, and give the same
habitat maps voxel by voxel.

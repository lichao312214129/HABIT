API Reference

HABIT v2.0 is API-first: the Python API is the product, and the CLI and YAML configuration files are thin shells over the objects documented here. The layered core is:

kernels → contracts → capability packages → spec / execution / adapters → recipes / report

Every component listed on this page is imported from its canonical capability package. The package root exports version metadata only. The declarative registry of the stable surface lives in habit/_public_api.py.

Stability. Symbols listed here are the canonical v2.0 public surface. Anything not listed here is internal and may change without notice.

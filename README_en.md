# HABIT

Habitat imaging of tumors: build habitat maps from a medical image and an ROI, then quantify volume, intratumoral heterogeneity, graph metrics, and radiomics.

## Install

Python **3.10–3.14**. Full steps: [Installation](https://lichao312214129.github.io/HABIT/tutorial/installation.html).

```bash
pip install habitat-analysis
```

Import name: `import habit`. From source: `pip install -e .`. Demo data: [Quickstart](https://lichao312214129.github.io/HABIT/tutorial/quickstart.html) (`habit.datasets.fetch_demo`). Example habitat YAML: [`config/`](config/).

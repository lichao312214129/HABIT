# HABIT Windows 轻量一键安装包 — 打包说明

面向维护者。构建脚本：`developer/build_lightweight_release.ps1`。

轻量包不携带已经安装好的 conda 环境。它携带锁定的 Python 3.10
环境合同、预编译 HABIT/PyRadiomics wheel、外部工具和 micromamba；
用户首次双击安装入口时才在包内 `.mamba/` 创建环境。

---

## 构建前准备

- Python 3.10 x64 的已验证 HABIT 构建环境
- `installer/vendor/` 下恰好一个：`pyradiomics-3.0.1-cp310-cp310-win_amd64.whl`
- `installer/vendor/micromamba/` 下固定版本的 `micromamba.exe` 和完整 `licenses/`
- `tools/bin/` 下的 `dcm2niix.exe`、`elastix.exe`、`transformix.exe`
- 建议工作区干净（未提交改动需显式加 `-SkipGitCleanCheck`）

---

## 构建命令

推荐双击 `developer\build_lightweight_release.bat`。它会提示输入构建 Python，
并保留 Git 工作区干净检查。PyRadiomics、micromamba 及外部工具均从仓库内
固定哈希的 vendor 资产读取。

也可从 PowerShell 手动执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass `
  -File developer\build_lightweight_release.ps1 `
  -BuildPython E:\conda\mconda\envs\py310\python.exe
```

可选参数：

- `-OutputDirectory`：默认写入仓库根目录 `dist/`
- `-SkipGitCleanCheck`：跳过 git 干净检查（仅调试用）

构建器会：

1. 在临时目录从过滤后的源码副本执行 `pip wheel`，生成非 editable HABIT wheel
2. 校验 C 扩展、内置 radiomics 参数与 wheel 平台标签
3. 按白名单组装发布树，校验 vendor SHA-256
4. 写入 `release_manifest.json` 并做工厂验收
5. 在 `dist/` 生成 `HABIT-light-v<version>.zip`

---

## 最终用户流程

1. 解压 ZIP 到 `D:\HABIT` 这类短英文路径。
2. 双击 `一键安装HABIT.bat`。
3. 安装自检通过后，双击 `启动HABIT命令行.bat`。
4. 仅在使用对应功能时，双击 `一键启用HABIT-AutoML.bat` 或
   `一键启用HABIT-进阶分析.bat`。
5. 兼容 NVIDIA 电脑可选双击 `一键启用HABIT-GPU.bat`；GPU 增强失败不影响默认环境。

默认锁不得包含仅供可选功能使用的重依赖：AutoML 只能依赖
`autogluon.tabular`，不能使用会引入 multimodal/timeseries 的
`autogluon` umbrella；Torch 仅属于 GPU 层，且 HABIT 不使用
`torchvision`。

## 发布给用户

1. 上传 `dist/HABIT-light-v<version>.zip`；ZIP 已包含 `config/` 及运行时
   外部工具（`tools/bin/`）。
2. 可按需单独上传网盘资源：
   - `demo_data.rar` — 演示数据
   - `tests.zip` — 仓库 `tests/`（排除 `.pytest_cache`、`__pycache__`、`*_log.txt`）
3. 用户文档：`docs/source/tutorial/installation.rst`

**维护者打包 tests.zip（Windows 示例）**

```powershell
cd F:\work\habit_project
# tests: exclude cache manually or use 7-Zip; ensure tests/ is top folder in zip
```

```bash
# Linux / macOS（仅打包 tests 资源时）
cd /path/to/HABIT
zip -r tests.zip tests -x "tests/.pytest_cache/*" -x "tests/**/__pycache__/*" -x "tests/*_log.txt"
```

## 常见问题

**Q: 打包环境平时使用了 `pip install -e .` 可以吗？**

A: 可以用于日常开发。发布构建会在临时源码副本中重新打 wheel，不依赖当前环境里的 editable 安装。

**Q: `dist/` 里会有什么？**

A: 默认是 `HABIT-light-v<version>.zip`。中间 wheel 在系统临时目录生成，再复制进 ZIP 内的 `tools/wheels/`，不会把构建中间产物留在仓库 `dist/`。

**Q: 每次发新版都要重新构建吗？**

A: 是。运行 `build_lightweight_release.ps1`（脚本会重新打 wheel 并校验）→ 上传新 ZIP。

**Q: macOS / Linux 用户怎么办？**

A: 当前轻量一键安装包面向 Windows。macOS / Linux 请按文档使用源码安装（`conda` + `pip install`）。

Features
========

Multi-sequence intensities (default), texture maps on one sequence
(all texture families), enhancement patterns, combining features, and
a plugin extractor without editing HABIT source.

Those numbers can replace the intensity in the feature table that the habitat model clusters, or sit next to it.">

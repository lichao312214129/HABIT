Building blocks
===============

* **HabitatSpec / Stage / Spec** — declare the analysis.
* **Atomic components** — extractors, preprocessors, supervoxelizers,
  fitters, assigners, feature families.
* **RunPolicy and backends** — serial by default in examples; process /
  resume / GPU on the Backends page.
* **HabitatModel** — saved definition (``.habitatmodel``).
* **Plugins** — register extractors without editing HABIT source.
* **Methods paragraph** — ``result.manifest.describe_methods()``.

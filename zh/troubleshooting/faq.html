FAQ#

Install#

找不到 ``habit`` ** ——未在 conda 环境中。Windows 请打开 **Anaconda Prompt （非普通 CMD），运行 conda activate habit 直至提示符显示 (habit) ，再 habit --version 。见 Installation 。

** pip install 失败 / 镜像缺包** — 请使用官方 PyPI：

pip install habitat-analysis -i https://pypi.org/simple

Windows 上 PyRadiomics — 勿 bare pip install pyradiomics （sdist 损坏）。安装与 Python 匹配的 Release v1.0.2 wheel，如 3.10:

pip install https://github.com/lichao312214129/HABIT/releases/download/v1.0.2/pyradiomics-3.1.0-cp310-cp310-win_amd64.whl

napari / ``PluginManifest`` / pydantic errors:

pip install "pydantic>=2.12,<3"
pip install "napari[pyqt5]" "npe2>=0.8.2" "pydantic!=2.11.*,>=2.8,<3" -i https://pypi.org/simple

napari 窗口闪一下即关闭 — 保持 show=True （默认）；调用会阻塞直到您关闭窗口。

** OptionalDependencyError ** —— 消息含缺失包的 pip install ... 命令。

Parquet / pyarrow — pip install pyarrow ，或在 YAML 设 habitats_results_format: csv 。

Run#

路径/文件错误 — 从项目根（含 config/ 的文件夹）运行。检查 data_dir / out_dir （不确定时用绝对路径）。

命令失败 — habit <cmd> --help; read processing.log in the output folder; validate with habit check-config -c <yaml>.

YAML 修改未生效 — 确认通过 -c 传入的文件；CLI --mode 会覆盖 YAML run_mode 。

Data#

ROI：与图像对齐的 NIfTI，或重采样掩膜（从 NIfTI 文件加载 ）。目录、松散文件、SimpleITK 或 NumPy：图像操作 。DICOM：之前：图像预处理 。

生境图#

为何我的生境图是一整块？ 通常因在患者间聚类特征而未做受试者级归一化。MR 强度为任意单位，扫描整体比训练更暗/更亮的新患者几乎全落入最暗或最亮质心。在 pool 前做受试者级预处理——例如 Spec("winsorize", {"winsor_limits": [0.05, 0.05]}) 再 Spec("minmax") ——如 用 Spec 的两步法生境 。原因及队列级预处理能/不能修复什么见 Concepts 。其他原因：生境过少（ fit 选 2）或 ROI 很小。

为何两次运行或两页得到不同生境图？ 两种情况。(1) 相同区域、不同编号：聚类按任意顺序编号生境，故一次拟合的「生境 2」可以是另一次的「生境 3」。匈牙利原型匹配后图一致：同一受试者、两次拟合：原型匹配 、两名受试者、相同 Spec：原型匹配 或 一步法组拟合：原型匹配 。两步法与池化体素拟合已共享一模型，无需匹配。(2) 真正不同区域：两次运行用了不同定义（其他阶段、预处理、超体素数、种子）或不同训练队列。比较两阶段列表与 cohort digest 中的 model.summary() 。相同 spec、种子与训练队列时，HABIT 逐体素给出相同标签，与后端无关。

HABIT 能否分析瘤周区域？ 可以，若自备瘤周掩膜；HABIT 无瘤周环生成器。掩膜按名查找：Subject 持 masks （ROI 名到掩膜）， subject.mask(roi_name) 返回一个。将环存为另一 ROI 文件夹如 masks/<subject>/peritumoral/<file> ，用 cohort_from_directory(DATA, modalities=MODALITIES, roi="peritumoral") 加载，extract 阶段同名 ROI（ Spec("raw", {"modalities": [...], "roi": "peritumoral"}) ）。环与瘤分开分析，除非自行合并掩膜。加载路径：图像操作 。

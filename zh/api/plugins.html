插件 introspection API#

稳定的 HABIT 插件发现与检查 API。

实现位于 habit.plugins.catalog 。v2 内置组件优先使用 plugin_catalog() 或 constructor_signature() 。

用户指南： Habitat Spec 组件目录 · 组件注册表 。发现内置与 entry-point 组件。参数顺序恒为 (name, domain) 。

类#

插件信息

描述在 HABIT 插件域中注册的一个组件。

PluginParamInfo

来自 v2 构造器的一个 Spec / Registry.create 参数。

PluginCatalogEntry

由构造器契约派生的一行目录（非手抄表）。

PluginLoadReport

报告已加载的外部 entry point 与非致命发现失败。

函数#

list_plugins

列出注册的 HABIT 扩展组件，而不暴露核心注册表。

get_plugin_info

返回某一已注册组件的元数据，或抛出清晰的 API 错误。

get_param_schema

若已注册，返回插件的旧版 Pydantic params_model 。

plugin_catalog

从各插件构造函数契约构建实时目录。

format_plugin_catalog_rst

将 plugin_catalog() 渲染为文档目录的 reStructuredText。

load_plugins

通过标准 Python 入口点加载声明的外部 HABIT 插件。

setup_logger

为 HABIT 模块或脚本配置 logger。

is_available

返回可选第三方模块是否可导入。

show_versions

返回 HABIT 与关键依赖版本，便于复现与调试。

check_component

返回 name 是否在 HABIT 插件域中注册。

 
from habit.plugins import get_plugin_info, list_plugins, load_plugins
from habit.supervoxel import SlicSupervoxelizer, SupervoxelizerRegistry

report = load_plugins(strict=False)
print(report.loaded, report.failures)

all_plugins = list_plugins()
habitat_only = list_plugins("habitat_model_fitter")

info = get_plugin_info("slic", "supervoxelizer")
print(info.name, info.domain, info.implementation, info.provider)

# Parameters live on the component constructor, not a Params model.
print(SupervoxelizerRegistry.available())
print(SupervoxelizerRegistry.constructor_signature("slic"))
slic = SupervoxelizerRegistry.create("slic", n_supervoxels=50)
slic = SlicSupervoxelizer(n_supervoxels=50)

load_plugins 容错#

  • strict=False （默认）——损坏的 entry point 记入 PluginLoadReport.failures 并以警告记录；发现继续

  • strict=True — 首次加载错误立即重新抛出

report = load_plugins(strict=False)
if report.failures:
    for name, message in report.failures.items():
        print("plugin failure:", name, message)

# CI / production gate: abort if any third-party plugin is broken
load_plugins(strict=True)

旧版复数域（如 habitat_features 、 models ）仍可解析但会发出 HabitDeprecationWarning ；请优先使用下列 v1 单数域。

v1 协议域#

将这些域字符串与 list_plugins / get_plugin_info 一起使用：

V1_DOMAINS = [
    "voxel_feature_extractor",
    "supervoxelizer",
    "supervoxel_feature_extractor",
    "habitat_model_fitter",
    "habitat_assigner",
    "habitat_feature_extractor",
    "combiner",
    "image_perturbation",
    "preprocessor",
    "table_preprocessor",
    "feature_selector",
    "classifier",
    "metric",
]
for domain in V1_DOMAINS:
    print(domain, [p.name for p in list_plugins(domain)])

枚举已注册名称:

for plugin in list_plugins():
    print(plugin.domain, plugin.name)

存在哪些 Spec / create 名称#

组件 __init__ 是唯一参数契约：类型、默认值、允许值或范围、验证及同名公开属性。 Registry.create("name", **kwargs) 转发这些构造参数。不要将参数表复制到 YAML 或 notebook——会过时。用 list_plugins / Registry.available() 查名称，并阅读构造器（或 Registry.constructor_signature ）获取参数。

from habit.plugins import list_plugins
from habit.table_preprocessing import TablePreprocessorRegistry

print([info.name for info in list_plugins("table_preprocessor")])
print(TablePreprocessorRegistry.constructor_signature("minmax"))
scaler = TablePreprocessorRegistry.create("minmax")

Registry.create / get_plugin_info 上的错误名称会列出该域中 已 注册的名称。

注册第三方插件#

External packages make components discoverable by declaring HABIT's entry point groups in their own packaging metadata. The group name is habit. followed by the domain string; v1.0 domains are the snake_case singular protocol names listed above (older plural group names remain honoured for legacy factories). HABIT itself declares no empty groups — setuptools strips them — the authoritative list is habit/api/plugins.py::_ENTRY_POINT_GROUPS.

在插件的 pyproject.toml 中：

[project.entry-points."habit.supervoxelizer"]
my_slic_variant = "my_package.my_module:MySupervoxelizer"

[project.entry-points."habit.voxel_feature_extractor"]
dce_hemodynamics = "my_package.features:register"

The registered object must implement the matching protocol from the capability package (for example Supervoxelizer) and expose a spec (see Spec、RunPolicy 和 YAML 同构). For voxel_feature_extractor, the entry point commonly points at a callable that performs @VoxelFeatureExtractorRegistry.register(...) (same pattern as other domains). After pip install of the plugin package, load_plugins() surfaces it and list_plugins("supervoxelizer") / list_plugins("voxel_feature_extractor") report provider="<distribution>".

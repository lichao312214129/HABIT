概念#

背景。 生境分析有独立的小型术语表。指南页面会使用这些词而不再长篇定义，故本页集中收录。

目的。 读完后应能读任意阶段列表（ HabitatSpec ）并说明各阶段做什么、哪些统计从哪些患者学习、保存模型含什么。

适用场景。 在阅读 入门教程 之前先通读一遍，之后若某篇指南链到此处术语再回来查阅。

图像与区域#

体素。 图像的三维像素。HABIT 仅分析 ROI 内体素。

ROI / 掩膜。 感兴趣区，通常为整瘤，与图像同网格的整数掩膜（0 = 背景）。演示中掩膜键为 LAP ，即勾画所用序列。

模态 / 序列。 受试者的一幅输入图像，例如一个 DCE 期相（ pre_contrast 、 LAP 、 PVP 、 delay_3min ）。同一受试者的所有序列必须与掩膜共享同一体素网格；这属于图像预处理（ 之前：图像预处理 ），发生在生境分析之前。

特征、超体素、生境#

体素特征。 描述单个体素的数值：各序列强度（ raw ），或其周围局部纹理（ voxel_radiomics ）。 extract 阶段每个 ROI 体素一行、每个特征一列。

超体素。 受试者内由 partition 阶段（k-means 或 SLIC）划分出的、特征相近的邻近体素小块；其特征向量为所含体素的均值。对每个受试者聚类数十个超体素比聚类每个体素更快、噪声更低。

生境。 特征相似的体素（或超体素）组。 fit 阶段学习生境定义（k-means：生境数与每生境一质心）； assign 给每体素最近质心 id。结果为生境图：每 ROI 体素涂生境 id 1、2、3、…

生境特征。 从生境图计算的数值，每名患者一行：体积分数、MSI（生境如何接触）、ITH 分数（肿瘤碎片化程度）、图指标、逐生境放射组学。定义： 特征公式 。

受试者级与队列级#

每一步要么是 受试者级 （一次只看一名患者），要么是 队列级 （看到全部训练患者池化行）。 pool 阶段为分界。

  • 受试者级 阶段在 pool 之前运行： extract 、置于 pool 之前的 preprocess 阶段，以及 partition 。它们仅使用该患者自身数据、不存储状态，且不会把一名患者的信息泄漏到另一名。新患者经历它们的方式与训练患者完全相同。

  • 在 pool 之后运行 队列级 阶段： preprocess 之后的 pool 与 fit 。它们在训练患者上学习一次；其状态（例如分箱边界与质心）保存在模型内，并在新患者上 原样 复用，从不在新患者上重新拟合。

同一组件名可在两侧。阶段列表中的位置决定是哪一个。

为何预处理重要#

MR 强度为任意单位：两台扫描仪或同机两次会话可对相同组织给出很不同灰度。跨患者聚类原始强度会把患者按整体亮度而非瘤内模式分组。

演示说明：两患者 raw 强度拟合，第三患者扫描整体更暗（动脉期 ROI 中位 545 对训练 864 与 976）约 85% 体素在最暗生境 — 一大块。仅队列预处理不能修复（最大生境仍占 52–67%）。受试者级归一化可以：winsorize 至各患者 5–95 分位，再 min-max 到 0..1，新患者显示四生境（分数 0.09–0.40）。即 用 Spec 的两步法生境 与 quickstart 所用定义。

权衡：每受试者 min-max 去掉绝对全瘤增强水平。生境则描述瘤内模式而非瘤整体亮度。若绝对水平对问题重要，作为单独全 ROI 特征报告。

三种生境设计#

阶段列表决定设计（ 入门教程 ）：

  • 两步法 —— partition 再 pool 再 fit 。每患者超体素，队列一个模型。生境 id 在各患者中含义相同。此为默认。

  • 一步法 ——无 pool ：各患者单独聚类。生境 id 不可跨患者比较；使用无标签摘要（ITH 分数、生境数）或先匹配标签（ 同一受试者、两次拟合：原型匹配 ）。

  • 直接池化 —— 先 pool 再 fit ，无 partition ：所有患者的所有体素一起聚类。编号共享，但矩阵随每个体素增长。

声明一项分析#

Spec。 注册组件名加其参数，例如 Spec("kmeans", {"n_supervoxels": 30}) 。可往返 YAML 并有指纹，结果可精确说明由何产生。

阶段。 分析中的一步： Stage("partition", Spec(...)) 。第一个参数是您选择的标签；HABIT 根据组件及其位置推断角色（extract、preprocess、partition、pool、fit、assign、quantify）。

HabitatSpec。 阶段有序列表加 random_seed ：整项研究定义。 Study 运行它（训练队列 fit_predict ，新患者 predict ）。YAML 的 spec: 块是同一对象。

.habitatmodel. 已保存的生境定义：质心、拟合的队列级预处理状态、完整阶段列表、定义队列的指纹与软件版本。 HabitatModel.load() 读回并为新患者贴标签而不重拟合（ 训练、保存并预测新患者 ）。

Methods 段落。 result.manifest.describe_methods() 根据实际运行起草稿件 methods 段（ 训练、保存并预测新患者 ）。

运行队列#

后端。 如何调度受试者：串行（在本进程中逐个）或工作进程池。更换后端只改变速度，不会改变生境标签。

RunPolicy。 一次运行的设置：backend、workers、单受试者失败时行为（ on_subject_failure ）、单受试者超时。

检查点。 已完成受试者结果写盘（ CheckpointStore ），中断运行可恢复而无需重算。

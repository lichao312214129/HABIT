预处理配置#

预处理配置参数#

本节记录 预处理 配置（ PreprocessingConfig ）。顶层键 preprocessing 持有步骤块；键须匹配 PreprocessorFactory 注册名；YAML 顺序即执行顺序。

DICOM 仅排序 使用 habit sort-dicom 以及一个单独的配置；请参见 DICOM 排序配置 。操作： 之前：图像预处理 。

示例配置文件：

data_dir: ./config/preprocessing/files_preprocessing.yaml
out_dir: ./preprocessed
auto_select_first_file: true

preprocessing:
  dcm2nii:
    images: [pre_contrast, LAP, PVP, delay_3min]
    dcm2niix_path: ./dcm2niix.exe
    compress: true
    anonymize: false

  n4_correction:
    images: [pre_contrast, LAP, PVP, delay_3min]
    num_fitting_levels: 4

  resample:
    images: [pre_contrast, LAP, PVP, delay_3min]
    target_spacing: [1.0, 1.0, 1.0]
    img_mode: bilinear

  registration:
    images: [pre_contrast, LAP, PVP, delay_3min]
    fixed_image: LAP
    type_of_transform: SyNRA
    metric: MI
    use_mask: false

  histogram_standardization:
    images: [pre_contrast, LAP, PVP, delay_3min]
    target_min: 0.0
    target_max: 100.0

  zscore_normalization:
    images: [pre_contrast, LAP, PVP, delay_3min]
    only_inmask: false
    clip_values: [-3, 3]

  adaptive_histogram_equalization:
    images: [pre_contrast, LAP, PVP, delay_3min]
    alpha: 0.3
    beta: 0.3
    radius: 5

save_options:
  save_intermediate: true
  intermediate_steps: [dcm2nii, n4_correction, resample]

processes: 2
random_state: 42

顶层（ ``PreprocessingConfig`` ）

字段

Default

描述

data_dir / out_dir

none（required）

相对路径相对含本 YAML 的目录解析

preprocessing

{}

步骤名 → 配置 dict；键须为已注册预处理器名

processes

1

须 >= 1 ；有效并行 min(config, CPU cores - 2) ，至少 1

random_state

42

numpy.random.seed 在 BatchProcessor.run() 条目

auto_select_first_file

true

目录多文件时是否自动选第一个

preprocessing_input_layout

habit_default

当前仅支持 habit_default 目录布局

save_options

见下表

中间结果持久化选项

预处理 ：每个步骤都共享公共字段 images （必填，非空列表）。

dcm2nii ：DICOM 转换

  • images ：模态键列表（ 必需 ）。

  • dcm2niix_path ：可执行文件或目录； 可选 ——省略则在 dcm2niix 搜索 PATH 。

  • 其他常见选项： compress 、 anonymize 、 filename_format 、 adjacent_dicoms 、 ignore_derived 、 crop_images 、 generate_json 、 verbose 、 batch_mode 、 merge_slices 、 single_file_mode 等（见源码）。

n4_correction

  • images （必填）； num_fitting_levels （默认 4）； num_iterations ； convergence_threshold ； shrink_factor ；可选 mask_keys 。

resample

  • images (required); target_spacing [x,y,z] mm; img_mode (image interpolation, default bilinear); padding_mode; align_corners. 掩膜 resampling uses nearest neighbor.

registration

  • images （必填，须含 fixed_image ）； fixed_image （必填）；floating 序列为 images 中除 fixed_image 外全部键。 勿用 YAML 字段 moving_images （实现不读且可能作为 ANTs 额外关键字传入）。

  • backend （可选）： ants （默认）、 simpleitk 、 elastix （调用官方 elastix/transformix 可执行文件；可选 elastix_path / transformix_path ）；见本页 registration 字段说明。

  • type_of_transform 、 metric 、 optimizer 等适用于 ants / simpleitk ； elastix 后端不使用这些键来驱动配准。文档中列出了 所有可选值 （ANTS 路径）；常见示例包括 Rigid 、 Affine 、 SyN 、 SyNRA 等。

  • use_mask ；可选 mask_keys ； replace_by_fixed_image_mask 。

  • elastix 专用 （ elastix 后端）：

    • elastix_parameter_files ：参数模板 .txt 文件；按数据类型与配准任务从 LKEB elastix Model Zoo 选择。

    • elastix_parameter_overrides ：覆盖参数值的 dict。

    • elastix_path 、 transformix_path 、 elastix_threads 。

  • 可通过额外键传入更多 ANTs 允许的参数（请谨慎使用）。

histogram_standardization

  • images （required）； percentiles ； target_min / target_max ；可选 mask_key （直方图统计）。

zscore_normalization

  • images （必填）； only_inmask ； mask_key （ only_inmask 为 true 时须在 data 中存在，如共享掩膜键或 mask_<modality> ）； clip_values 。

adaptive_histogram_equalization

  • images （必填）； alpha 、 beta ∈ [0,1]； radius 为 int 或 (x,y,z)。

save_options （ SaveOptionsConfig ）

字段

Default

描述

save_intermediate

false

是否写入中间目录

intermediate_steps

[]

非空时，仅所列步骤写入中间结果； save_intermediate: true 且为 空列表 时写入每一步

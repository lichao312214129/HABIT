生境 inside each 受试者#

逐患者异质性评分。

背景。 有些问题针对每个肿瘤本身： 该病灶有多异质？ 此时不需要队列共享的生境定义。每个肿瘤可拆成自有生境（一步法设计），患者随后用不依赖生境 id 编号的数字描述：需要多少生境及碎片化程度。

Purpose. You will cluster each of the five demo patients alone, let the elbow rule pick the number of 生境 per patient, and build a one-row-per-patient table of label-free heterogeneity summaries: number of 生境, ITH score and MSI energy, with a bar chart of the ITH score.

何时使用。 当问题是逐患者异质性评分、患者差异过大不宜共用定义，或仅有一名患者时，用一步法。若需跨患者比较 生境 2 （如“增强生境占比”），勿用一步法：请用 用 Spec 的两步法生境 的两步法，或先匹配逐患者生境（一步法组拟合：原型匹配 ）。

分析定义。 参考分析见 用 Spec 的两步法生境 ，但去掉三阶段：无 partition （直接对体素聚类）、无 pool （各受试者单独拟合），因而无队列级 binning （无池化行可学习 bin 边界）。受试者级 winsorize + z-score、k-means 拟合器（2..10 候选、elbow、 n_init=10 ）与 seed 0 不变。为加快页面省略 graph 族。

关键术语。 完整定义见 Concepts 。

  • one-step — fit 与 assign 在每位受试者自己的体素上运行；无 partition 与 pool ，每位患者有私有模型与各自质心。

  • 标签切换 — 两次独立聚类对相似组织编号不同，于是一名患者的生境 1 不是另一名的生境 1。按生境比较患者前必须匹配 id。

  • 无标签摘要 -- a number that stays the same if the 生境 ids of a 患者 are renumbered (e.g. 1<->3). Only those can be compared across 患者 here.

  • ITH score — 生境碎片化： 1 - (1 / S_total) * sum_i(S_i,max / n_i) ， S_i,max 为生境 i 的最大连通片， n_i 为其片数；0 = 每个生境为单块。

  • MSI energy — 生境接触矩阵上的平方和（MSI = 各对生境及生境与自身接触频率）。重编号 id 仅置换矩阵元素，故和不变。

备注

The demo has no clinical outcomes. In your own study the table at the end is what you join to outcomes (by the subject column); this page stops at the table.

声明一步法分析#

阶段列表无 partition 且无 pool 。无 pool 时， fit 在各受试者体素上逐受试者运行一次，elbow 规则为每位患者分别选生境数。

此处两个受试者级阶段有效：仅用患者自身统计。队列级阶段（两步法页 binning 后的 pool ）不适用：它在池化训练行上学习，而本设计无池化。

spec = HabitatSpec(
    name="inside_each_subject",
    stages=(
        # extract: one intensity column per DCE phase, voxels inside the ROI.
        Stage("extract", Spec("raw", {"modalities": list(MODALITIES), "roi": ROI})),
        # preprocess (subject-level): clip each column to that patient's
        # own 1st..99th percentile.
        Stage("preprocess", Spec("winsorize", {"winsor_limits": [0.01, 0.01]})),
        # preprocess2 (subject-level): rescale each column to 0..1 with that
        # patient's own min and max.
        Stage("preprocess2", Spec("zscore")),
        # No partition, no pool, no preprocess_cohort.
        # fit (per subject): k-means on this patient's voxels, 2..10
        # habitats tried, elbow rule, 10 restarts per candidate count.
        Stage(
            "fit",
            Spec(
                "kmeans",
                {
                    "min_habitats": 2,
                    "max_habitats": 10,
                    "validation": "elbow",
                    "n_init": 10,
                },
            ),
        ),
        # assign: nearest centroid of THIS patient's own model.
        Stage("assign", Spec("nearest_centroid")),
        # quantify: volume, MSI and ITH per patient.
        Stage("volume", Spec("volume")),
        Stage("msi", Spec("msi")),
        Stage("ith", Spec("ith_score")),
    ),
    random_seed=0,
)
# Without pool there is no single habitat_model: one model per subject,
# keyed by subject id.
result = Study(spec).fit_predict(
    cohort,
    backend=backend_from_policy(
        RunPolicy(backend="serial", on_subject_failure="continue")
    ),
)
print("cohort-level model:", result.habitat_model)
print("per-subject models:", list(result.subject_models))

各患者自行选择生境数量#

每个私有模型保留各自的 elbow/Kneedle 报告。以下为第一名患者的曲线。图保留该患者的 Kneedle K。HABIT 验证 elbow 与 kneedle 规则相同：对 k-means 惯性（簇内平方和）运行 KneeLocator ，曲线凸、方向递减（Satopaa 等，2011，IEEE ICDCS）。将 k 与惯性归一化到单位正方形，连接首尾点弦，取距弦最远的 k；平滑曲线常使该膝点偏右于肉眼弯曲处。文献中 “elbow” 指观察簇内离散度随 k 变化（Thorndike RL，1953，Psychometrika 18(4):267-276）— 非二阶差分公式。离散曲率 elbow（视觉 elbow，可计算）最大化惯性二阶差（HABIT v1.0 前 elbow）；非 Thorndike 公式。生境图保留 Kneedle K；其他 K 仅在下表。完整对比：聚类算法与生境数 。

first_id = cohort[0].subject_id
first_model = result.subject_models[first_id]
report = first_model.preprocessing_state["selection_report"]
candidates = [int(k) for k in report["candidates"]]
inertia = np.asarray(report["scores"][report["methods"][0]], dtype=float)


def discrete_curvature_elbow_k(cluster_range, inertia_scores):
    """Return k maximizing the second difference of inertia (pre-v1.0 elbow)."""
    values = np.asarray(inertia_scores, dtype=float)
    cluster_range = [int(k) for k in cluster_range]
    if values.size < 3:
        return int(cluster_range[int(np.argmin(values))])
    return int(cluster_range[int(np.argmax(np.diff(values, n=2))) + 1])


k_kneedle = int(first_model.n_habitats)
k_discrete = discrete_curvature_elbow_k(candidates, inertia)
from habit.habitat_model import KMeansHabitatModelFitter

逐患者异质性表#

生境 id 对各患者私有：一患者的生境 2 不等于另一患者的生境 2，故 habitat_2_volume_fraction 等逐生境列 不得 跨行比较。仅保留无标签摘要：

  • n_habitats -- the count chosen by the 肘部法则 for that 患者;

  • ith_score — 碎片化，重编号 id 不变；

  • energy （MSI）— 接触矩阵上的平方和，重编号亦不变。

此页面未使用其他 MSI 摘要。

features = result.features.frame.set_index("subject")
n_habitats = pd.Series(
    {sid: model.n_habitats for sid, model in result.subject_models.items()},
    name="n_habitats",
)
heterogeneity = pd.concat(
    [n_habitats, features[["ith_score", "energy"]].rename(columns={"energy": "msi_energy"})],
    axis=1,

heterogeneity.index.name = "subject"
print(heterogeneity.round(3).to_string())

如何解读结果#

  • 无队列级模型（ habitat_model 为 None ）；五名患者各有自己的模型。

  • 本运行中 elbow 规则为 subj001、subj002、subj003 选 K = 4，为 subj004、subj005 选 K = 5。

  • ITH 分数从 0.620（subj002）到 0.964（subj005）。对单个体素聚类会留下许多小碎片，本设计中接近 1 很常见；患者间互比，勿用固定截断。

  • 生境更多的患者碎片化方式更多，请与 ith_score 一并阅读 n_habitats 。

  • 五名演示患者且无结局：这些数字展示流程，不代表任何临床关联。

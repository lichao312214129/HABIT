提取体素强度#

背景。 生境分析按输入图像外观对体素聚类。首阶段 extract 将 ROI 内每体素变为可聚类的数字行。

目的。 得到一名受试者的体素特征表（每个 ROI 体素一行、每个 DCE 期相一列），以及带 ROI 轮廓的动脉期切片，以便检查哪些体素进入分析。

关键词。

  • ROI / 掩膜 — 感兴趣区，通常为整瘤，存为整数掩膜；仅分析其内体素（0 = 背景）。

  • 体素特征 —— 描述单个体素的数值（例如各 DCE 期相的强度，或局部纹理值）；每个特征一列。

  • extract 阶段 — 将图像 + ROI 转为体素特征表。 raw 为最简提取器：原样复制强度。

输入：一个 Subject 。输出： VoxelFeatureField 。阶段： extract_voxel_features 与 raw 。

加载单受试者#

将 DATA / MODALITIES / ROI 改为您的预处理布局。sphinx_gallery_thumbnail_number = 1

from pathlib import Path

import matplotlib.pyplot as plt

from habit.contracts import cohort_from_directory
from habit.datasets import fetch_demo
from habit.viz import plot_intensity_slice
from habit.voxel_features import RawVoxelFeatures

DATA = fetch_demo()
# Three DCE phases: unenhanced, arterial, and portal-venous.
MODALITIES = ("pre_contrast", "LAP", "PVP")
ROI = "LAP"
# Read the folder tree into a Cohort and keep only the first subject;
# every extractor is called on one subject at a time.
subject = cohort_from_directory(DATA, modalities=MODALITIES, roi=ROI)[0]
print(subject.subject_id, sorted(subject.images))

    masks/<subject_id>/<roi>/<one mask file>

  cohort = cohort_from_directory(DATA, modalities=("LAP",), roi="LAP")

Swap DATA / modalities / roi to match your tree. Mask key is often the

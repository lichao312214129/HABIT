引用与致谢#

引用 HABIT#

若在科研工作中使用 HABIT，请引用您实际运行过的软件版本。引文元数据位于仓库根目录的 CITATION.cff （GitHub 显示为 "Cite this repository"）：

Li C, Dong M, HABIT Contributors. HABIT: Habitat Analysis - Biomedical Imaging Toolkit. Version 3.0.0. Apache-2.0. lichao312214129/HABIT

该软件尚未注册 DOI；在存在之前，请引用存储库 URL 和确切版本。

在方法学部分，让 HABIT 根据实际运行的内容而非凭记忆起草段落：

result = Study(spec).fit_predict(cohort)
print(result.manifest.describe_methods())

其中列出已执行阶段及其参数、随机种子、软件版本以及被排除的受试者。完整示例见 训练、保存并预测新患者 。可像任何草稿一样审阅并编辑。

开源社区#

HABIT 依赖许多优秀的开源项目，包括但不限于：

SimpleITK — 医学图像处理 PyRadiomics — 放射组学特征提取 scikit-learn — 机器学习算法 pandas 与 numpy — 数据处理 matplotlib 与 seaborn — 可视化

InMoose 共识聚类 （Žiga Sajovic；Solène Weill 与 Guillaume Appé）——以 GPL-3.0-or-later 形式随 habit/third_party/inmoose/ 提供的共识聚类例程；HABIT 其余部分仍为 Apache-2.0。

我们向这些项目的开发者与维护者致以诚挚的敬意与感谢。

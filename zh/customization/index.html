扩展 HABIT#

此页面是 v1 生境 插件 路径：实现一个协议，注册它，可选地将其作为入口点发布。第三方不应需要分叉 HABIT。

内置 Spec 名称与构造参数见 Habitat Spec 组件目录 。发现 API 见 插件 introspection API 。无插件的算术公式用内置 expression 体素提取器（将自定义特征提取器作为插件 ）。

v1 注册表与 entry points#

  • 域字符串 = snake_case 单数协议名（如 voxel_feature_extractor 、 habitat_model_fitter ）

  • Entry-point 组 = habit.<domain>

  • 用 list_plugins("voxel_feature_extractor") / load_plugins() 发现

  • 用 Registry.create(name, **params) 创建并从 HabitatSpec 引用名称

通常扩展的生境域：

  • Voxel feature extractors ： VoxelFeatureExtractorRegistry

  • 超体素化器 / 超体素特征

  • Habitat model fitters / assigners / habitat feature extractors

每个插件适用三契约：

  1. 行为 — 实现匹配协议（带 spec 可调用，通常 __call__(subject) ）。

  2. Registration —— 进程内 @Registry.register("name") ，或 import 注册模块的 entry point。

  3. Parameters — 在组件构造函数（因而 Spec("name", {…}) ）上。用 Registry.constructor_signature("name") 查询。

重要

Registration decorators run only when the Python module is imported. External plugins must be imported (or loaded via load_plugins()) before the workflow starts. For in-tree development, import the module from the corresponding subpackage __init__.py.

v1 自定义体素特征提取器#

用于需邻域、嵌入或超出内置 expression DSL 的 DIY 公式。可运行 Custom features 图库用三幅肝 DCE（动脉相对增强、动脉-门静脉洗出、动脉-延迟洗出）。

步骤 1：实现协议并注册

import numpy as np
from habit.contracts import VoxelFeatureField
from habit.contracts.subject import Subject
from habit.voxel_features import (
    VoxelFeatureExtractorRegistry,
    aligned_image,
    build_voxel_field,
    roi_voxels,
)
from habit.spec import Spec

PHASES = ("pre_contrast", "LAP", "PVP", "delay_3min")
NAMES = (
    "relative_enhancement_lap",
    "relative_washout_pvp",
    "relative_washout_delay",
)

@VoxelFeatureExtractorRegistry.register("dce_hemodynamics")
class DCEHemodynamics:
    def __init__(self, phases=PHASES, roi=None, eps=1e-8):
        self.phases = tuple(phases)
        self.roi = roi
        self.eps = float(eps)

    @property
    def spec(self) -> Spec:
        return Spec(
            name="dce_hemodynamics",
            params={"phases": list(self.phases), "roi": self.roi, "eps": self.eps},
        )

    def __call__(self, subject: Subject) -> VoxelFeatureField:
        mask, inside, index = roi_voxels(subject, self.roi)
        pre, lap, pvp, delay = (
            aligned_image(subject, phase, mask, owner="dce_hemodynamics")[inside]
            for phase in self.phases
        )
        values = np.column_stack(
            [
                (lap - pre) / (pre + self.eps),
                (lap - pvp) / (lap - pre + self.eps),
                (lap - delay) / (lap - pre + self.eps),
            ]
        )
        return build_voxel_field(
            subject, mask, index, NAMES, np.asarray(values), self.spec,
        )

步骤 2：在 HabitatSpec 中使用

from habit.spec import HabitatSpec, Spec, Stage
import habit.recipes as recipes

spec = HabitatSpec(
    name="diy",
    stages=(
        Stage(
            "extract_voxel_features",
            Spec(
                "dce_hemodynamics",
                {"phases": ["pre_contrast", "LAP", "PVP", "delay_3min"]},
            ),
        ),
        Stage("preprocess", Spec("zscore", {"across_features": False})),
        Stage(
            "fit",
            Spec(
                "kmeans",
                {
                    "min_habitats": 2,
                    "max_habitats": 5,
                    "validation": "elbow",
                    "n_init": 3,
                },
            ),
        ),
        Stage("assign", Spec("nearest_centroid")),
        Stage("quantify", Spec("volume")),
    ),
    random_seed=42,
)
result = recipes.Study(spec=spec).fit_predict(cohort)

步骤 3（可选）：作为第三方包发布

在插件 pyproject.toml 中:

[project.entry-points."habit.voxel_feature_extractor"]
dce_hemodynamics = "my_package.features:register"

其中 register() 执行 @VoxelFeatureExtractorRegistry.register 调用（或导入执行该操作的模块）。用户随后:

from habit.plugins import load_plugins
load_plugins()

See 将自定义特征提取器作为插件 for a runnable demo covering both expression and a custom plugin, and 插件 introspection API for discovery.

Other 生境 domains follow the same pattern: implement the protocol, register on the matching registry, reference the name from HabitatSpec. Catalogs and constructor signatures: Habitat Spec 组件目录.

扩展原则#

遵循协议。 自定义生境组件携带 spec 并接受该域的类型化契约（ Subject 、特征场、生境图等）。L0–L3 插件内勿加 I/O。

注册稳定名称。 使用描述性 snake_case（ dce_hemodynamics ，非 dcehemo ）。在该域内保持唯一。

记录参数。 构造器参数为公开契约。在 docstring 中给出默认值与单位。

Test. 在小 Subject 上单测插件；再在单 demo 案例上经 recipes.Study(spec=…).fit_predict 运行。

图像预处理与表格 ML#

Image-preprocessing steps and tabular-ML models / selectors are not the public extension story. Those v0.1 factory tours (PreprocessorFactory, ModelFactory, SelectorRegistry, …) are frozen. Maintainers who still need them should read the archived pages in the repository:

  • developer/sphinx_archive/extension_points.rst

  • developer/sphinx_archive/customization_index.rst

FAQ#

如何调试自定义组件？ 启用日志，对合成 Subject 写单元测试，并在接入 HabitatSpec 前直接调用插件。

如何共享自定义组件？ 发布带 habit.<domain> entry point 的小包，或上游贡献并附测试。

如何处理额外依赖？ 文档说明；非核心栈放在插件 extras，而非 HABIT 必需依赖。

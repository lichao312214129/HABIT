特征公式#

HABIT 原生定义、公式及在 生境图 上（生境存在后）提取特征的输出 CSV 列。强度 / 纹理 / 形状放射组学遵循 PyRadiomics 实现的 IBSI 定义（3-D averaged 纹理）。ROI 级、体素级放射组学与 3-D 形状匹配 FeatureExtractor.execute() —— 见 传统放射组学 上 PyRadiomics alignment 。官方数字体膜数值： 传统放射组学 。PyRadiomics 目录：PyRadiomics Feature Reference。

每一页： 输出 → 定义 → 公式 （如有）→ 输出列 → 实现 → 参考文献 （如有）。

轻量内置族（ volume 、 msi 、 ith_score 、 graph ）在 feature_types 中为同级。拓扑 walkthrough： 生境 graph network 特征 。CLI / YAML 书签： 图拓扑特征 。

作为 生境输入 的体素级纹理（ voxel_radiomics ）是另一套产品面——切片图见 纹理特征图：单独与联合强度 ，而非 feature_types CSV 族。已注册的提取器名称（输入侧与图侧）： Habitat Spec 组件目录 。

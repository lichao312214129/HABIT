传统放射组学#

Config ： feature_types 含 traditional

输出 ： raw_image_radiomics.csv

定义#

从肿瘤 ROI 内各 预处理后图像模态 提取 PyRadiomics 特征。ROI 为从生境标签图导出的 二值掩膜 （标签 \(ge 1\) 体素 → 前景）；不用解剖 masks/ 文件。否则忽略生境标签——特征反映 raw（多 delay）图像上瘤内信号与纹理。

实现#

  • 参数文件： params_file_of_non_habitat （可选；省略时使用捆绑的 roi 预设 → habit/resources/radiomics/parameter.yaml ）

  • 代码： habit/compat/engines/habitat_extraction/habitat_features/builtin_plugins.py （ TraditionalRadiomicsPlugin ）→ habitat_radiomics.py

输出列#

列模式

描述

{pyradiomics_feature}_of_{modality}

One column per PyRadiomics 特征 × image 模态 under the 受试者 folder

（排除）

名称含 diagnostic 的列在导出前丢弃

特征定义#

HABIT 用 PyRadiomics 3.1 公式（遵循 IBSI；Zwanenburg et al., Radiology 2020）提取一阶、GLCM、GLRLM、GLSZM、GLDM（IBSI NGLDM）、NGTDM 与 3-D 形状特征。纹理聚合为 IBSI 3-D averaged （13 个唯一 3-D 角度均值），非 3-D merged。 habit radiomics 、 traditional / each_habitat / whole_habitat 特征类型、 supervoxel_radiomics 、 voxel_radiomics 与 native C 路径使用相同定义。

PyRadiomics 对齐#

ROI 级放射组学、体素级放射组学与 3-D shape 均与 PyRadiomics 3.1 FeatureExtractor.execute() 在相同图像、掩膜、标签与设置（ binWidth 、 voxelArrayShift 、distances 等）上一致。

ROI 级 （ habit radiomics / traditional 、 each_habitat 、 whole_habitat 、默认 union_bin=false 的 supervoxel_radiomics ）：一阶、GLCM、GLRLM、GLSZM、GLDM、NGTDM。 traditional / whole_habitat 直接调用 execute() 。 each_habitat 与默认 supervoxel_radiomics 使用按标签分箱的原生 C 路径；相对 execute() 约在相对误差 1e-10 内一致（Energy / TotalEnergy 在浮点 ULP 量级）。

Shape （仅 ROI）：PyRadiomics original_shape_* / execute() 的 computeShape 。Shape 为整 ROI 网格量；无逐体素 shape 图。

体素级 （ voxel_radiomics ）：经 execute(..., voxelBased=True) 计算一阶与纹理。CPU 路径 就是 该提取器（预裁剪不改变数值）。Torch / CUDA 使用相同公式；纹理相对 CPU 约在 \(10^{-15}\) ，一阶百分位数约在 \(10^{-8}\) （分位数算法差异）。设 torch_dtype: float64 可最接近 CPU 结果。

门禁： tests/kernels/test_supervoxel_native_parity.py 、 tests/kernels/test_ibsi_digital_phantom.py 、 tests/kernels/test_*_gpu_parity.py 。

以下 不是 PyRadiomics，且不得与 execute() 对照： graph 、 msi 、 ith_score 、 volume 、 local_entropy ，以及超体素 mean / std / percentile 。

supervoxel_radiomics 与 union_bin=true 是不同离散化（union 掩膜上单一共享灰度）。 JointAverage / Autocorrelation / HighGrayLevel* 不会与逐 ROI execute() 一致；此为预期，非公式 bug。

两种约定须与 IBSI 手册对照阅读，而非与之对立：

  • Kurtosis 为 Pearson 峰度。IBSI 报告 超额 峰度（Fisher，正态 = 0）。HABIT / PyRadiomics = IBSI + 3。

  • HABIT 不会 提取其未实现的 IBSI 族：GLDZM、局部强度峰、强度-体积直方图、Moran's I 或 Geary's C。已弃用的 PyRadiomics 形状名称（Compactness 1/2、Spherical disproportion）也不计算。

IBSI-1 Phase 1 数字体膜#

表用官方 IBSI 数字体膜（5×4×4 体素，2 mm 各向同性，74 体素 ROI；强度含 1、3、4、6、9）来自 theibsi/data_sets <https://github.com/theibsi/data_sets/tree/master/ibsi_1_digital_phantom>`_（CC-BY-4.0）及 IBSI 手册 **dig. phantom / 3-D averaged** 参考值（`Image features）。设置对齐 Phase 1：无插值， binWidth=1 ， symmetricalGLCM=True ， distances=[1] ，NGLDM \(alpha=0\) ， voxelArrayShift=0 。

HABIT 是该特征族走快速路径时的原生 C + CPU 公式值；形状特征是 traditional_radiomics 所用的 PyRadiomics execute 值。HABIT 与 PyRadiomics 列一致。相对已发表 IBSI 数值的剩余差距来自 Kurtosis 约定（见上）或 IBSI 手册中的有效位数（例如 556 对 556.333 ）。回归测试加载同一对 NIfTI： tests/kernels/test_ibsi_digital_phantom.py 。

图拓扑特征#

Output#

habitat_graph_features.csv

graph 为 内置 轻量生境特征族（ habitat_feature_extractor 名 graph ）。优先域/公开 API；旧 habit.compat.graph_plugin shim 于 v2.0.0 移除。

数值定义在 L0 habit.kernels.habitat_graph ，对领域提取器、核 helper extract_graph_features() 与可选 habit.viz 图（相同节点/边构造）一致。本页与该源码一致，不另造理论。该指标族改编自 PathPrism（Liang et al., Cancer Cell 2026）组织病理 tissue-graph 方法；HABIT 将其用于 2-D / 3-D 生境图并文档化下文体素索引与 VOI 细化。

符号与域#

设 \(L:Omega o{0,1,ldots,K}\) 为 2-D 或 3-D 体素格 \(Omegasubsetmathbb{Z}^{d}\) （\(din{2,3}\) ）上的整数生境标签图。

  • 背景。 标签 \(0\) 为背景，在节点提取、图构建及下述肿瘤 VOI 测度 \(V\) 中 排除 。非图节点。

  • 生境标签。 \(mathcal{H}={kinmathbb{Z}:k>0,; existsmathbf{x}inOmega,; L(mathbf{x})=k}\). When the caller supplies expected_labels, every listed id still emits columns even if it is absent from this map (empty graph → all metrics 0), so 队列 tables keep a stable schema (same contract as ITH 分数).

  • 坐标。 质心与距离为 索引/体素单位 ，非毫米。内核内不应用 spacing。下列尺寸伴生量仅在所有标签图重采样到相同各向同性 spacing 后跨受试者物理可比。不校正采集分辨率变化。

  • 未定义算术。 空序列、零分母、非有限 NetworkX 输出，以及低于指标最小尺寸的图表将返回 0.0 （导出表中永远不会是 NaN）。

肿瘤 VOI（仅用于尺寸归一化伴随量）：

\[V = \#\{\mathbf{x}\in\Omega: L(\mathbf{x})\ne 0\}, \qquad \delta_{\mathrm{bbox}} = \bigl\|(\mathbf{u}_{\max}-\mathbf{u}_{\min}+\mathbf{1})\bigr\|_{2}\]

其中 \(mathbf{u}_{min},mathbf{u}_{max}\) 为非背景体素的 inclusive 索引界。若 \(V=0\) ，不写 *_norm 伴随列。

图构建#

节点（连通区域）#

对每个生境 \(kinmathcal{H}\) ：

  1. 构建二值掩膜 \(M_k=mathbf{1}[L=k]\) 。

  2. 若 erosion_radius \(rge 1\) ，用结构元 \(M_k\) 对 \(r\) 做 \(S\) 次二值腐蚀， border_value=0 。HabitatGraphFeatureOptions 默认 \(r=0\) （关）：邻接与接触按绘制标签测量。正 \(r\) 可在标注与连边前收缩各生境。

  3. 用 scipy.ndimage.label 与结构 \(S\) 标记（可能腐蚀后）掩膜的连通分量：

    • connectivity='full' （默认）：二维中的对角线包含的8邻域 / 三维中的26邻域（ generate_binary_structure(rank=d, connectivity=d) ）；

    • connectivity='face' ：2-D 4 邻 / 3-D 6 邻（ generate_binary_structure(rank=d, connectivity=1) ）。需要 4/6 连通时仍可用 face。

  4. Drop a component \(C\) if \(|C| <\) min_region_voxels (default 1).

  5. Default node_method='uniform_grid' 跳过按分量拆分。整个肿瘤 VOI 涂上边 block_size \(b\) （默认 \(b=8\) 体素 ，非毫米）的 全局 轴对齐立方格子，原点为 VOI 包围盒最小值。立方体占用比例超过 block_min_coverage （默认 0.2 ；格级过滤）时保留。每个保留立方体内，每个生境的每个连通分量在该子区域体素索引质心处成为独立节点，故一立方体可贡献多节点。小于 min_region_voxels 的格内片段丢弃。 node_method='component' 为旧规则：若 subdivide_region_voxels \(s>0\) 且 \(|C|>s\) ，将 \(C\) 拆为边 \(b\) 的轴对齐网格块（默认 \(s=1000\) ）。体素集 \(B\) 的块 保留 仅当

    \[|B| / b^{d} ;>; mathrm{block_min_coverage}\]

    (strict inequality; default coverage 0.2). Each kept block becomes its own node. If no block passes, or subdivision is off, the whole component is one node.

每个保留的区域（组件或模块）都是一个节点

\[v=(k,;mathrm{id},;mathbf{c}_{v},;n_{v},;mathrm{bbox}_{v})\]

质心 \(mathbf{c}_{v}\) = 区域体素 索引 均值（float），\(n_{v}=|B| ` 或 :math:`|C| ` ，及半开包围盒。节点 id 为稳定字符串 ``h{k}_c{id}`\) 。

边：质心距离#

edge_method='centroid_distance' （可选）。设 :math:` au=` distance_threshold （默认 5.0 体素单位）。不同节点 \(u,v\) 间存在无向边当

\[距离约束：$d(u,v)=|mathbf{c}_{u}-mathbf{c}_{v}|_{2} le au$\]

使用 KD 树实现 (scipy.spatial.cKDTree.query_pairs / query_ball_point)。

  • Single-habitat graph for label \(k\): nodes of habitat \(k\) only; every pair with \(d\le\tau\) is an edge of type centroid_distance.

  • 成对图 针对无序标签 \((a,b)\) 、\(a<b\) ：\(a\) 节点与 \(b\) 节点在 \(dle au\) 下的 inter 边。若 pairwise_include_intra_edges 为 true（默认），同 :math:` au` 下各标签内也加 intra 边。下方界面指标仅用 类间邻居 （isolated ratio、R21/R12、pair degree 族）；全图指标（modularity、assortativity、betweenness、components、extended efficiency）用该对的完整双标签图（inter + 可选 intra），非全生境并图。它们不是纯界面分数。

来自 w 的边权重 edge_weight ：

\[\begin{split}w = \begin{cases} 1 & \text{if none (default)} \\ d(u,v) & \text{if distance} \\ 1/(d(u,v)+10^{-6}) & \text{if inverse-distance} \end{cases}\end{split}\]

contact_voxels is unused for this method (stored as missing).

边：最小体素距离#

edge_method='min_distance' （ 默认 ）。复用 distance_threshold :math:` au` （默认 5.0 体素索引单位）。默认 8 体素立方时，面邻立方相连（最近体素相距一跳）。立方间空一格最近体素距离约 8，大于 :math:` au=5` ，故不连。当两节点 \(u,v\) 体素集分离的最近体素距离满足条件时存在无向边

\[d_{min}(u,v)=min_{pin B_{u},,qin B_{v}}|p-q|_{2} le au\]

这是两体素集间的最小 pairwise 距离， 非 Hausdorff 距离（max-of-mins）， 非 质心距离：两大连通区边界可很近而质心很远。用体素索引 KD 树实现（ scipy.spatial.cKDTree ）。单生境与 pairwise（inter / 可选 intra）图结构与 centroid_distance 相同。存储边 distance 即此 \(d_{min}\) （故 avg_edge_distance / std_edge_distance 概括最近体素长度，非质心长度）。 edge_weight 为 distance 或 inverse_distance 时用 \(d_{min}\) 。 contact_voxels 未用（存为缺失）。

边：体素邻接（可选）#

edge_method='adjacency' （可选）。将每节点绘制到整数 id 数组（背景与未请求标签保持 0 ）。对 半空间 中每个唯一邻接偏移（第一个非零分量 \(=+1\) ，故每个无序体素对只计一次）：

  • corner （默认）：最多 \(d\) 个非零偏移（2-D 8 连通，3-D 26 连通）。2-D 中 edge 与 corner 一致；

  • edge: up to two non-zero offsets (8-conn / 18-conn);

  • face ：一个非零偏移量（4-连通 / 6-连通）。在需要4/6连通性时，面保持可用。

Let \(N_{mathrm{adj}}(u,v)\) be the number of neighbouring 体素 pairs whose ids are \((u,v)\). An edge exists iff

\[N_{mathrm{adj}}(u,v) ge mathrm{adjacency_min_voxels}\]

(default 10). An edge exists when two regions are adjacent and the contact (shared-boundary) 体素 count is >= 10, measured on the (possibly eroded) 掩膜. Default erosion_radius=0 means the 生境 labels as drawn. contact_voxels \(=N_{mathrm{adj}}\). Distance on the edge is still the centroid Euclidean distance (used by distance summaries). Weight is 1 unless edge_weight='contact_voxels', in which case \(w=N_{mathrm{adj}}\). Pairwise intra / inter filtering matches the centroid-distance case.

成对指标#

Prefix pair_h{a}_h{b}_ with \(a<b\). This graph contains only nodes of 生境 \(a\) and \(b\). It is not a union of all 生境 in the map: pair_h1_h2_modularity does not see H3, and there is no default all-生境 mega-graph. single_h{k}_* is the one-生境 graph for label \(k\) only.

Let \(V_a,V_b\) be the node sets of the two labels, \(n_1=|V_a|\), \(n_2=|V_b|\), \(N=n_1+n_2\), and \(E_{\mathrm{inter}}\) the inter-class edges only (edge_type != 'intra'). Interface metrics below use cross-class neighbors / \(E_{\mathrm{inter}}\) only (isolated ratio, R21/R12, degree_cv, degree_entropy, degree_skewness). "Whole-graph" below means the full two-label pair graph (inter + optional intra inside this pair), not the whole-tumour habitat map. Those pair topology columns (components, modularity, assortativity, betweenness, extended efficiency) are therefore not interface-only scores.

扩展指标#

由 include_extended_metrics 启用（默认 true ；传 false 省略）。小世界用 Humphries 解析 ER \(S\) ，除非 graph_null_sampler 为 config 或 rewire 。\(G^{star}\) 为 分析子图 ：输入图连通且有边则用输入图；否则用最大连通分量（空/无边图保持原样）。\(n^{star}=|V(G^{star})|\) 。\(0\) 或 \(n^{star}<2\) 无边时下列整合指标为 \(G^{star}\) 。

小世界性与随机图零模型#

Watts and Strogatz [Watts1998] called a network small-world when it has lattice-like 聚类 and random-graph path lengths. Humphries and Gurney [Humphries2006] [Humphries2008] turned that into one ratio \(sigma=(C/C_{mathrm{rand}})/(L/L_{mathrm{rand}})\), with \(sigma>1\) commonly read as small-world. HABIT uses that ratio. \(C\) is transitivity (global 聚类, not the mean of local coefficients) and \(L\) is mean shortest-path length on \(G^{star}\), matching NetworkX sigma. The exported value is 0 unless \(n^{star}ge\) extended_min_nodes (default 10), \(G^{star}\) is connected, and it has at least one edge. This is a descriptor, not a hypothesis test.

HABIT 写入 一 列 small_world_sigma 。三个 graph_null_sampler 值为 \(C_{mathrm{rand}}\) 与 \(L_{mathrm{rand}}\) 的互斥 零模型 。非三种不同观测图指标。勿当作可互换，勿发明第四种 sampler。

config — configuration model. 保持观测度序列的 stub-matching 随机图 [Newman2001] [Milo2004]。\(C_{mathrm{rand}}\) 与 \(L_{mathrm{rand}}\) 为 small_world_nrand 接受简单连通图均值（默认 100 ）。配对失败或图不连通则拒绝。快速采样无法填满 ensemble 时，HABIT 回退 Maslov–Sneppen 混合观测图， nrand 不静默缩小。

rewire — Maslov–Sneppen。 从观测图副本出发做双边交换（约每条边 small_world_niter 次交换，默认 100 ）[Maslov2002]_。每个节点度保持不变；连接关系被混合。NetworkX smallworld.sigma / random_reference 即此实现（NetworkX 默认 ensemble 仅 nrand=10 ；HABIT 用 100 ）。Rubinov 与 Sporns [Rubinov2010] 综述了脑图的同一保度思想。

选择采样器以匹配引用，而不是为了“改进” \(sigma\) ：

  • 按 2008 论文报告 Humphries S → analytic 。

  • 将 NetworkX sigma → rewire 。

  • 教科书配置-模型集成 → config 。

若运行使用 analytic 或 config ，稿件中勿写 "rewire"。

生境图是 空间 的。三种 null 均不约束体素坐标或接触几何，故 lattice-like 图相对任一 null 都可能 inflate \(C\) 。这是成像图上经典小世界检验的已知局限 [Rubinov2010]，非用随意生成器替换这些 null 的理由。

聚类、平均路径长度以及局部/全局效率使用与 NetworkX 相同的无权跳数距离。根据请求，集合是堆叠的邻接批次（如果安装了 Numba 则在 CPU 上运行；否则使用 NumPy；当满足 graph_null_device='auto' 且任务足够大时，使用一次 PyTorch CUDA Floyd–Warshall 启动）。

拓扑的零模型比较#

Some graph quantities are dimensionless but still vary systematically with node count, edge count, degree sequence, or the statistical behavior of a maximum/minimum. Dividing them by VOI volume is not a valid correction. For a hypothesis about organization beyond the degree sequence, compare the observed value against degree-preserving random graphs instead.

适用于 avg_clustering 、 avg_path_length 、 diameter 、 global_efficiency 、 local_efficiency 、 modularity 、 degree_assortativity 、原始 betweenness 最大/标准差、 node_local_efficiency_min/std 及 pairwise habitat_assortativity 。 degree_entropy 与度摘要由保度 null 固定，需考虑样本量的估计而非此 null。默认 small_world_sigma 用解析 Erdős–Rényi null [Humphries2008]。 rich_club_coefficient 用一张保度图（或可选 ensemble）。报告 graph_null_sampler ，勿将这些当作体积归一化量。

habit.kernels.compare_graph_to_degree_preserving_null() is an explicit, opt-in API. It preserves every node's degree, node count, and edge count, but intentionally does not preserve connected components, spatial coordinates, edge distances, contact area, or habitat labels. It must not be used to normalize contact_voxels_*, edge-distance, spatial-dispersion, or node-volume features. Check its is_valid result: a zero Z score for an invalid result is a sentinel, not evidence of no difference.

本特征族不声称的内容#

  • 距离为 体素索引单位 ，非物理毫米。 avg_edge_distance 随边方法：默认 min_distance 为最近体素 \(d_{min}\) ， centroid_distance / adjacency 为质心欧氏。除非各向同性 1 mm 间距，勿当作毫米长度。

  • Small-world \(sigma\) is Humphries' ratio on a possibly tiny 生境 graph. The default analytic sampler is the closed-form ER approximation, not a NetworkX Monte-Carlo draw. config / rewire are degree-preserving ensembles. None of these is Watts–Strogatz inference for a brain connectome, and the value is forced to 0 below extended_min_nodes.

  • Empty or missing 生境 emit zeros, not missing values. A 队列 mean of a single_h3_* column therefore mixes true structure with absent-label zeros unless you filter on graph_num_habitats / presence.

  • 图特征描述 划分几何 。它们不标识生物细胞类型，也不证明生境为克隆区域。

Implementation#

  • Capability implementation: habit/habitat_features/graph.py (GraphHabitatFeatures)

  • Kernels: habit/kernels/habitat_graph/ (nodes.py, edges.py, proximity.py, metrics.py, extended_metrics.py, features.py, traversal.py). The kernel crops the label map to the tumour VOI (plus one voxel of pad) before nodes, edges, metrics, and size-normalized companions run, so a full-CT habitat image is not scanned as background. min_distance builds one global edge table. Voxel-neighbour sweep and dual-lattice range search run only when node_method='uniform_grid' (grid_origin and grid_block_size are set). The Chebyshev radius is 0 when T < 1, else floor((T-1)/B)+1 for user block_size=B and distance_threshold=T. component nodes keep the all-pairs closest-voxel walk. One all-sources BFS per graph yields Brandes betweenness, closeness, mean path length, and diameter (NetworkX definitions). Default extract keeps edges as integer arrays and runs those hop / clustering / component columns on CSR (Compressed Sparse Row) adjacency -- no NetworkX object. Extended columns (default on) reuse those same arrays; small-world is the Humphries analytic ER \(S\) unless the user asks for config / rewire. Hop metrics use compiled CSR Brandes (serial sources so several graphs can run in threads). Louvain modularity uses a CSR Blondel sweep (the partition can differ from NetworkX seed=0). Node default stays uniform_grid.

  • YAML block: GraphFeatureBlock in habit/schemas/workflows/habitat.py

  • Recipe + CSV name: habit/recipes/features.py, habit/adapters/extract_io.py (stem habitat_graph_features)

  • Figures: habit/viz/habitat_graph.py (matplotlib; 3D needs napari)

  • Removed v2.0.0 shim: habit/compat/graph_plugin.py (use domain / API)

开始之前#

先执行一次此操作，然后每个 CLI 书签都是复制 → 编辑 ★ → 运行。 pip install habitat-analysis 之后 不 需要 git clone。

生境分析是核心（指南：Examples ）。以下步骤仅配置终端、 config/ 与演示影像包。

1. 终端与环境#

先打开 conda 终端。Windows：开始（Win10 常左下；Win11 常中下）→ Anaconda3 → Anaconda Prompt ，或搜索 Anaconda Prompt — 不要用普通 CMD/PowerShell。细节与截图：Installation 。

conda activate habit          # prompt must show (habit)
habit --version

2. 工作目录 + demo 配置#

Pick any folder you own as <work_dir>. Materialize the bundled demo YAML tree (shipped inside the wheel; not demo_data):

mkdir D:\my_habit_work        # Windows — use your path
cd D:\my_habit_work
habit copy-demo-config --dest .

# macOS / Linux
mkdir -p ~/my_habit_work && cd ~/my_habit_work
habit copy-demo-config --dest .

ls config                     # or: Test-Path config

Python:

from habit.utils.demo_config_utils import copy_demo_config
copy_demo_config(r"D:/my_habit_work")

下列命令假定 shell cwd 为此 <work_dir> 。

3. 演示数据（首次运行）#

包 拆分 — 仅生境用户需要 imaging； habit model / habit cv 才加 ML。imaging 下载一次 ；HABIT 打印路径与文件夹树（该树即自有数据的约定）。

Imaging — 自 <work_dir>:

habit fetch-demo --work-dir .

# same thing in Python
from habit.datasets import fetch_demo
DATA = fetch_demo()          # prints DATA, subjects, series, example files

  • 缓存： ~/.habit_data/demo-data-v1/preprocessed （ HABIT_DATA 覆盖）。后续调用不再下载。

  • --work-dir . 将 <work_dir>/demo_data/preprocessed 链到该缓存，使随附 YAML 路径可用。

  • 包内模态： pre_contrast / LAP / PVP / delay_3min

  • 预处理树已存在——首次可跳过 preprocess

  • 如果 GitHub 被屏蔽，请备份共享：Download preprocessed.zip （代码 9bi3 ）

表格 ML （ ml_data.zip ，可选）：

  • Download ml_data.zip — extract code: atnp

  • Extract to demo_data/ml_data/ (e.g. breast_cancer_dataset.csv)

  • 若 zip 顶层为 ml_data/ ，解压到 demo_data/

4. YAML 中的路径#

  • 多数随附配置：相对路径自 YAML 文件目录 解析（故 ../../demo_data/... ）。

  • Documents with version: '1.0' / *_v1.yaml: paths as written; run from <work_dir> or use absolute paths.

  • 优先 D:/data/... ；路径含空格时才加引号。

5. 安全 YAML 编辑#

  • 缩进用空格（勿 Tab）； key: value ；小写 true / false

  • 首次运行：仅修改 ★ 必须编辑 字段

不运行仅验证:

habit check-config --config config/habitat/config_habitat_two_step.yaml

接下来：图像操作 — 选择目录，松散的 NIfTI、SimpleITK 或 NumPy。每个图库脚本中都会出现相同的 DATA / MODALITIES / ROI 旋钮。DICOM 是 之前：图像预处理 ，而不是加载路径。

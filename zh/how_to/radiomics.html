传统放射组学#

备注

无 생境图的全 ROI 放射组学。指南： 量化栖息地 。 生境图上 特征： 量化栖息地 。

目标：整 ROI PyRadiomics 无 生境图。生境特征用 之后：用于统计 / ML 的生境特征 。ROI 级、体素级放射组学与 3-D shape 对齐 PyRadiomics execute() ；数字体膜表与对齐说明见 传统放射组学 。

运行演示#

habit check-config --config config/radiomics/config_traditional_radiomics.yaml
habit radiomics --config config/radiomics/config_traditional_radiomics.yaml

你的数据#

★ Edit paths.images_folder (folder with images/ + masks/), paths.out_dir, and processing.process_image_types (模态 names).

成功： paths.out_dir 下特征表。

有图时的逐生境表叠加相同解剖。该图 非 上文 habit radiomics （全 ROI 无标签）。由特征提取 gallery 生成（ 量化栖息地 ）。复现:

python docs/source/examples/scripts/feature_extraction_demo.py

该脚本中的绘图调用 (ROI = "LAP"):

from habit.viz import plot_habitat_overlay

fig = plot_habitat_overlay(subject.image(ROI), habitat_map, title="habitats")
